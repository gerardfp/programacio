1. Treballant amb String

Operacions bàsiques amb String

Aquestes són les operacions més habituals que utilitzaràs per treballar amb text:

  • text.length(): retorna el nombre total de caràcters de la cadena.
  • text.charAt(index): retorna el caràcter a la posició indicada (el primer caràcter sempre és a la posició 0).
  • text.toUpperCase() / text.toLowerCase(): retorna el text convertit a majúscules o a minúscules.
  • text.trim() / text.strip(): elimina els espais en blanc sobrants dels extrems.
  • text.substring(inici, fi): extreu un fragment de text des de la posició inici fins a fi - 1.
  • text.contains("paraula"): retorna true si el text conté la paraula indicada.
  • text.startsWith("prefix") / text.endsWith("sufix"): comprova com comença o acaba un text.
  • text.replace("vell", "nou"): canvia totes les aparicions d'un text per un altre.
  • text.equals(altre): compara si dos textos tenen exactament el mateix contingut (true o false).
  • text.equalsIgnoreCase(altre): compara dos textos ignorant majúscules i minúscules.
  • text.split("delimitador"): divideix el text en un array de cadenes utilitzant el delimitador indicat.
void main() { String nom = " Maria Garcia "; println("Original: '" + nom + "'"); println("Longitud: " + nom.length()); println("Sense espais: '" + nom.trim() + "'"); println("En majúscules: " + nom.toUpperCase()); println("Primer caràcter: " + nom.trim().charAt(0)); println("Conté 'Garcia'? " + nom.contains("Garcia")); println("Subcadena (0..5): " + nom.trim().substring(0, 5)); // Maria println("Substitució: " + nom.replace("Garcia", "Pérez")); println("És igual a 'Maria Garcia'? " + nom.trim().equals("Maria Garcia")); String frase = "Hola, com estàs?"; String[] paraules = frase.split(" "); // paraules = { "Hola,", "com", "estàs?" } println("Paraules de la frase:"); println(paraules[0]); // Hola, println(paraules[1]); // com println(paraules[2]); // estàs? }

Format de dades amb .formatted()

Quan hem de mostrar xifres amb un nombre concret de decimals, alinear columnes o construir missatges amb variables, podem aplicar el mètode .formatted(...) directament sobre qualsevol cadena de text o Text Block:

Els especificadors de format més comuns són:

  • %s: per incrustar cadenes de text.
  • %d: per a nombres enters (int, long).
  • %.2f: per a nombres decimals (double) amb exactament 2 xifres decimals.
  • %n: per afegir un salt de línia independent del sistema operatiu.
void main() { String producte = "Portàtil"; double preu = 899.95; int quantitat = 2; // .formatted() substitueix els especificadors pels valors indicats: String linia = "Producte: %-12s | Unitats: %2d | Preu: %8.2f €".formatted(producte, quantitat, preu); println(linia); String total = "Total a pagar: %.2f €".formatted(preu * quantitat); println(total); // Funciona de manera idèntica amb Text Blocks per a plantilles multilínia: String factura = """ =========== FACTURA SIMPLIFICADA =========== Article: %s Total: %.2f € ============================================ """.formatted(producte, preu * quantitat); println(factura); }

2. Lectura de Dades per Teclat: Scanner

Per demanar dades a l'usuari a través de la consola i llegir la seva resposta utilitzem Scanner. Com que forma part del paquet d'utilitats de Java, cal afegir la sentència import java.util.Scanner; a l'inici del fitxer:

Per començar a llegir, preparem un lector vinculat a l'entrada estàndard del sistema (System.in):

Scanner scanner = new Scanner(System.in);

Segons el tipus de dada que esperem rebre, farem servir el mètode adequat:

  • scanner.nextLine(): llegeix tota la línia de text fins que l'usuari prem la tecla Enter.
  • scanner.next(): llegeix només la següent paraula (s'atura en trobar un espai en blanc o salt de línia).
  • scanner.nextInt(): llegeix un nombre enter (int).
  • scanner.nextDouble(): llegeix un nombre decimal (double).
  • scanner.nextBoolean(): llegeix un valor booleà (true o false).
import java.util.Scanner; void main() { Scanner scanner = new Scanner(System.in); print("Com et dius? "); String nom = scanner.nextLine(); print("Quants anys tens? "); int edat = scanner.nextInt(); print("Quina alçada tens en metres (ex: 1,75)? "); double alcada = scanner.nextDouble(); println("Hola " + nom + ", tens " + edat + " anys i fas " + alcada + "m!"); }

3. Operacions Matemàtiques: Math

Math proporciona un conjunt complet de funcions matemàtiques i constants. Està disponible directament a qualsevol programa Java sense necessitat d'afegir cap instrucció import.

S'utilitza escrivint directament Math. seguit del nom de l'operació o constant que necessitem:

  • Math.PI: nombre pi (approx).
  • Math.sqrt(x): calcula l'arrel quadrada ($\sqrt{x}$).
  • Math.pow(base, exponent): calcula la potència $\text{base}^{\text{exponent}}$ (retorna sempre un double).
  • Math.abs(x): calcula el valor absolut (elimina el signe negatiu d'un número).
  • Math.max(a, b) / Math.min(a, b): retorna el valor més gran o el més petit entre dos números.
  • Math.round(x): arrodoneix un nombre decimal a l'enter més proper.
  • Math.floor(x): arrodoneix cap avall a l'enter inferior més proper.
  • Math.ceil(x): arrodoneix cap amunt a l'enter superior més proper.
  • Math.random(): genera un nombre decimal aleatori entre 0.0 (inclòs) i 1.0 (exclòs).
void main() { double radi = 5.0; double area = Math.PI * Math.pow(radi, 2); println("Àrea del cercle: " + area); double arrel = Math.sqrt(144); println("Arrel de 144: " + arrel); // 12.0 println("Màxim entre 45 i 80: " + Math.max(45, 80)); // 80 println("Mínim entre 45 i 80: " + Math.min(45, 80)); // 45 println("Valor absolut de -15: " + Math.abs(-15)); // 15 println("Arrodonir 4.7: " + Math.round(4.7)); // 5 println("Sòl (floor) de 4.7: " + Math.floor(4.7)); // 4.0 println("Sostre (ceil) de 4.2: " + Math.ceil(4.2)); // 5.0 }

4. Generació de Valors Aleatoris: Random

Quan volem generar valors a l'atzar amb més flexibilitat (nombres enters en intervals concrets, daus, cartes o simulacions), la utilitat Random del paquet java.util (import java.util.Random;) és la més recomanada.

Primer preparem el generador:

Random random = new Random();

I després podem utilitzar les seves operacions:

  • random.nextInt(limit): genera un enter a l'atzar entre 0 i límit - 1.
  • random.nextInt(start, end): genera un enter entre start i end - 1.
  • random.nextDouble(): genera un decimal aleatori entre 0.0 i 1.0.
  • random.nextBoolean(): genera un valor booleà (true o false) amb un 50% de probabilitat.
import java.util.Random; void main() { Random random = new Random(); // Simulació d'un dau de 6 cares: int dau = random.nextInt(1, 7); println("Ha sortit el dau: " + dau); // Llançament d'una moneda: boolean esCara = random.nextBoolean(); println("Ha sortit cara? " + esCara); // Probabilitat decimal: double percentatge = random.nextDouble() * 100; println("Percentatge d'èxit: %.1f%%".formatted(percentatge)); }

🚀 Hay una API para (casi) todo

Hasta ahora has aprendido a programar. Pero Java tiene una biblioteca enorme que permite hacer muchísimas cosas sin tener que programarlas desde cero.

Aquí tienes pequeñas piezas de Lego: cada una hace una cosa sencilla. Prueba a cambiar sus parámetros, repetirlas, combinarlas con if, for, while o Random... ¿Qué serías capaz de construir?

💡 La idea: no necesitas aprenderte estas API. Descubre que existen y experimenta con ellas.

🤯 Y ahora... combina las piezas

Lo interesante no es aprender estas instrucciones de memoria. Lo interesante empieza cuando las combinas con lo que ya sabes.

🤖 Abrir un programa y escribir dentro

new ProcessBuilder("notepad").start(); Thread.sleep(2000); new Robot().type("¡Esto lo ha escrito Java!");

Java abre el Bloc de notas, espera dos segundos y escribe en él. ¿Qué podrías hacer si cambias el texto, el tiempo y las acciones del robot?

🎵 Componer una canción

int[] notas = {60, 62, 64, 65, 67, 69, 71, 72}; for (int nota : notas) { canal.noteOn(nota, 100); Thread.sleep(300); canal.noteOff(nota); }

Cambia las notas. Cambia la duración. Repite algunas. Cambia el instrumento. Añade silencios. ¿Puedes hacer que Java toque una canción?

🖱️ Crear una automatización

Robot r = new Robot(); r.mouseMove(500, 300); Thread.sleep(500); r.click(); Thread.sleep(500); r.type("Hola");

Has construido una pequeña macro. Ahora puedes cambiar las coordenadas, las esperas y las acciones. ¿Puedes automatizar una tarea que haces habitualmente?

🧱 Piensa en piezas de Lego: una instrucción puede parecer poca cosa. Pero puedes repetirla, cambiar sus parámetros y combinarla con otras. Muchas cosas grandes empiezan con una pieza muy pequeña.
