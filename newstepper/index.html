Laboratori de Proves: Stepper 2.0

Simulador automàtic d'execució Java, suport complet de bucles (while, for) i desglossament explícit de les fases del for.

Com hem resolt els bucles i les parts del for?

Ara l'Stepper disposa de dos modes que treballen conjuntament:

  1. Mode Auto-Simulació (Zero esforç): Només escrius el codi Java. El motor executa el bucle de veritat, repeteix les iteracions, actualitza la memòria, i per a cada for anuncia explícitament la fase: Inicialització, Condició, Cos i Modificació.
  2. Mode Declaratiu Personalitzat: Si vols escriure explicacions pròpies, pots afegir l'atribut part="init", part="cond", part="body" o part="update" per ressaltar automàticament la subexpressió corresponent i mostrar la xapa identificativa.

🔄 Repetició Real de Bucles

El bucle no va només de dalt a baix: en cada iteració la traça torna a pujar a avaluar la condició fins que esdevé falsa.

🏷️ Fases del for Explicades

Distingeix clarament les 4 fases amb xapes visuals: Inicialització Condició Cos Modificació

🎯 Ressaltat Sub-expressió

Dins la capçalera for (init; cond; update), només es ressalta el fragment actiu en cada pas.

Demostració 1: Bucle while amb Repetició Real

Aquest stepper s'ha generat automàticament a partir del codi font. Observa com a cada iteració torna a pujar a la línia 3 per avaluar la condició, actualitza la memòria i finalitza quan n > 0 és fals:

int n = 3; int fact = 1; while (n > 0) { fact *= n; n--; } println("Fact: " + fact);

Demostració 2: Bucle for amb Indicació Explícita de les 4 Fases

Aquest és l'exemple clàssic de la Unitat 2 (int n = 3; for (int i = 0; i < n; i++) print(i + " ");). Fixa't en les xapes superiors que indiquen exactament quina part del for s'executa:

int n = 3; for (int i = 0; i < n; i++) { print(i + " "); }

Demostració 3: Bucle amb Entrada de Teclat (Scanner)

El simulador també llegeix de la cua d'entrades de teclat (amb l'atribut in="2, 5") i executa el bucle complet sumant els valors:

int ini = scanner.nextInt(); int fin = scanner.nextInt(); int sum = 0; for (int i = ini; i <= fin; i++) { sum += i; } println(sum);
