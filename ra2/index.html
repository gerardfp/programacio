Fonaments d'Objectes i Classes

En Java, gairebé tot gira al voltant dels objectes. Un objecte representa una entitat del món real o un concepte del programa que conté:

  • Estat (dades / atributs): La informació que emmagatzema l'objecte.
  • Comportament (mètodes): Les accions o operacions que l'objecte sap fer.

Una classe és el motlle, plantilla o definició a partir de la qual es creen (instancien) els objectes concrets utilitzant l'operador new.

Treballant amb cadenes: La classe String

String és una classe fonamental de Java que representa cadenes de text. En ser un objecte, disposa d'un conjunt molt potent de mètodes:

void main() { String nom = " Maria Garcia "; println("Longitud: " + nom.length()); println("Sense espais: " + nom.trim()); println("En majúscules: " + nom.toUpperCase()); println("Conté 'Garcia'? " + nom.contains("Garcia")); println("Subcadena: " + nom.trim().substring(0, 5)); // Maria }

Lectura de dades per teclat: Scanner

Per a llegir dades que l'usuari introdueix per la consola podem utilitzar la classe Scanner del paquet java.util:

import java.util.Scanner; void main() { Scanner scanner = new Scanner(System.in); print("Com et dius? "); String nom = scanner.nextLine(); print("Quants anys tens? "); int edat = scanner.nextInt(); println("Hola " + nom + ", tens " + edat + " anys!"); }

Mètodes d'instància enfront de mètodes estàtics

Hi ha dos tipus essencials de mètodes en Java:

  • Mètodes d'instància: S'invoquen sobre un objecte concret creat amb new (ex: scanner.nextLine() o text.toUpperCase()).
  • Mètodes estàtics: Pertanyen a la classe en general i s'invoquen directament amb el nom de la classe, sense necessitat de crear cap objecte (ex: Math.sqrt(), Integer.parseInt()).
void main() { // Math és una classe d'utilitats amb mètodes estàtics: double arrel = Math.sqrt(144); double potència = Math.pow(2, 8); int maxim = Math.max(45, 80); println("Arrel de 144: " + arrel); // 12.0 println("2^8: " + potència); // 256.0 println("Màxim: " + maxim); // 80 }

Generació de valors aleatoris: Random

La classe java.util.Random permet generar números a l'atzar per a simulacions, jocs i proves:

import java.util.Random; void main() { Random random = new Random(); int dau = random.nextInt(1, 7); // Genera un enter entre 1 i 6 (inclusiu) println("Ha sortit el número de dau: " + dau); }

🚀 Modo extra: Hay una API para (casi) todo

Hasta ahora has aprendido a programar. Pero Java tiene una biblioteca enorme que permite hacer muchísimas cosas sin tener que programarlas desde cero.

Aquí tienes pequeñas piezas de Lego: cada una hace una cosa sencilla. Prueba a cambiar sus parámetros, repetirlas, combinarlas con if, for, while o Random... ¿Qué serías capaz de construir?

💡 La idea: no necesitas aprenderte estas API. Descubre que existen y experimenta con ellas.

🤯 Y ahora... combina las piezas

Lo interesante no es aprender estas instrucciones de memoria. Lo interesante empieza cuando las combinas con lo que ya sabes.

🤖 Abrir un programa y escribir dentro

new ProcessBuilder("notepad").start(); Thread.sleep(2000); new Robot().type("¡Esto lo ha escrito Java!");

Java abre el Bloc de notas, espera dos segundos y escribe en él. ¿Qué podrías hacer si cambias el texto, el tiempo y las acciones del robot?

🎵 Componer una canción

int[] notas = {60, 62, 64, 65, 67, 69, 71, 72}; for (int nota : notas) { canal.noteOn(nota, 100); Thread.sleep(300); canal.noteOff(nota); }

Cambia las notas. Cambia la duración. Repite algunas. Cambia el instrumento. Añade silencios. ¿Puedes hacer que Java toque una canción?

🖱️ Crear una automatización

Robot r = new Robot(); r.mouseMove(500, 300); Thread.sleep(500); r.click(); Thread.sleep(500); r.type("Hola");

Has construido una pequeña macro. Ahora puedes cambiar las coordenadas, las esperas y las acciones. ¿Puedes automatizar una tarea que haces habitualmente?

🧱 Piensa en piezas de Lego: una instrucción puede parecer poca cosa. Pero puedes repetirla, cambiar sus parámetros y combinarla con otras. Muchas cosas grandes empiezan con una pieza muy pequeña.
