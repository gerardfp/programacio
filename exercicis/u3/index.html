1. Mètodes de la classe Scanner i Format de Dades

Avalua si coneixes quin mètode d'Scanner s'ha d'utilitzar segons el tipus de dada i com es dona format a la informació.

Fes coincidir els mètodes de la classe Scanner amb el tipus de valor que llegeixen.

nextInt()
int
nextBoolean()
boolean
nextFloat()
float
next()
String

Invoquem el mètode next() i introduïm el número 9 a l'entrada estàndard, quin tipus de dada serà?

String
char
int
float

Quin especificador de format hem d'utilitzar a String.format() o printf per a mostrar un decimal amb exactament dues xifres decimals?

%.2f
%2d
%s.2
%.2decimal

2. Exercicis Pràctics d'Objectes i Utils del JDK

Exercicis proposats

  • Comptador de caràcters: Demana a l'usuari el seu nom complet i mostra quants caràcters té en total (sense comptar els espais), el primer caràcter i l'últim caràcter en majúscules.

  • Generador d'àlies: Llegeix el nom i el cognom d'una persona i genera un àlies combinant les 3 primeres lletres del nom i les 3 primeres lletres del cognom en minúscules.

  • Dau aleatori: Utilitza la classe Random o Math.random() per simular el llançament de dos daus de 6 cares i mostrar la suma obtinguda.

  • Tiquet de compra amb format: Demana el nom d'un article, el preu unitari i la quantitat, i mostra un tiquet alineat i formatat usant String.format() o System.out.printf() amb dues xifres decimals.
