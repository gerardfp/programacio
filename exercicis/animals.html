Exercici: Jerarquia Animals

Herència: Animals

Implementa la jerarquia de classes d'animals següent:

classDiagram Animal <|-- Mamifero Mamifero <|-- Perro Mamifero <|-- Gato Mamifero <|-- Caballo class Animal { +String nombre +String tipoAlimentacion +int edad } class Mamifero { +int gestacion } class Perro { +String raza } class Gato { +String pedigri } class Caballo { +String comida +int ejercicio }

Crea els constructors amb crida a super() i sobreescriu toString() a cada subclasse.
