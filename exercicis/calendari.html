Exercici: Calendari d'Exàmens

Gestió de Dates: Calendari d'Exàmens

Aplicació per a gestionar el calendari d'exàmens d'un institut. Permet introduir i consultar les dates dels exàmens.

classDiagram Calendario o-- Examen Examen o-- FechaHora FechaHora o-- Fecha FechaHora o-- Hora class Calendario{ +List~Examen~ examenes } class Examen{ +String asignatura +String aula +FechaHora fechaHora } class FechaHora { +Fecha fecha +Hora hora } class Fecha { +int ano +int mes +int dia } class Hora { +int hora +int minuto }

Escriu un programa que afegeixi 3 exàmens al calendari i mostri la planificació per pantalla de forma ordenada.
