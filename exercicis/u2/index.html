2. Estructures Repetitives (Bucles for, while, do-while)

Calcula el nombre d'iteracions i el resultat del programa en executar bucles.

El següent codi calcula la suma dels números en el rang ini a fin (inclusiu). El resultat es va emmagatzemant en la variable acumulador.

int accumulator = 0; for (int i = start; i <= end; i++) { accumulator += i; }

Quin dels següents codis calcula la multiplicació dels números en el rang?

int accumulator = 1; for (int i = start; i <= end; i++) { accumulator *= i; }
int accumulator = 0; for (int i = 1; i <= end; i++) { accumulator *= i; }
int accumulator = 1; for (int i = start; i <= end; i *= 1) { accumulator += i; }
int accumulator = 1; for (int i = 1; i <= end; i++) { accumulator += i; }

3. Salts de Control (break i continue)

Comprova com s'interrompen o es continuen els bucles en trobar aquestes sentències.

Què imprimeix el següent codi?

for (int i = 0; i < 11; i++) { if (i % 2 != 0) { continue; } print(i + " "); }

Quants números imprimex el següent programa?

for (int i = 0; i < 5; i++) { println(i); if (i < 3) { continue; } else { for (int j = 0; j < 5; j++) { println(j); } } }

    Un parc d'atracciones cobra segons l'edat:

    • 65 anys o més: 7 €

  7. if2switch

    Transforma el següent codi amb if-else a un codi amb switch:

    String tipo = IO.readln("Tipo de tu Pokémon (fuego, agua, planta, eléctrico, tierra, roca): "); String debilidad; if (tipo.equals("fuego")) { debilidad = "Agua, Tierra y Roca"; } else if (tipo.equals("agua")) { debilidad = "Planta y Eléctrico"; } else if (tipo.equals("planta")) { debilidad = "Fuego"; } else if (tipo.equals("eléctrico")) { debilidad = "Tierra"; } else if (tipo.equals("tierra") || tipo.equals("roca")) { debilidad = "Agua y Planta"; } else { debilidad = "Tipo desconocido: ¡consulta la Pokédex!"; } IO.println("Débil ante: " + debilidad);
