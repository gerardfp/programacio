  19. El robot aspirador

    Un robot aspirador recorre una habitación siguiendo una línea recta. Sabemos desde qué posición comienza, a qué distancia queremos que llegue y cuántos centímetros avanza en cada movimiento.

    Escribe un programa que pida:

    • La posición inicial.
    • La posición del objetivo.
    • La distancia que avanza el robot en cada movimiento.

    El programa debe mostrar la posición del robot después de cada movimiento, empezando por la posición inicial.

    El robot debe seguir avanzando hasta que supere el objetivo, y se debe mostrar su posición final.

    Por ejemplo, si comienza en la posición 0, el objetivo está en 100 cm y avanza 30 cm cada vez:

    Posición inicial: 0 Posición objetivo: 100 Distancia por movimiento: 30 0 30 60 90 120

    El 120 se muestra aunque el objetivo sea 100, porque es la primera posición que supera el objetivo. Después de mostrar 120, el programa debe terminar.

    Requisitos:

    • Utiliza un bucle for.
    • Utiliza break para terminar el bucle.
    • No utilices variables auxiliares para controlar el bucle.
