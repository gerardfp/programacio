Exercicis U7: Persistència

Exercicis de Fitxers, JSON/XML i Bases de Dades

  • Comptador de línies: Llegeix un fitxer de text amb Files.readAllLines(Path) i compta el nombre total de línies i paraules.

  • Còpia de seguretat: Programa una utilitat que creï una còpia d'un fitxer afegint l'extensió .bak utilitzant Files.writeString().

  • Registre de notes CSV: Guarda i recupera una llista d'alumnes i qualificacions en un fitxer separat per comes.

  • Exportació a JSON: Serialitza una col·lecció d'objectes a format JSON per intercanvi de dades.

  • Consulta a Base de Dades (JDBC): Estableix una connexió amb una base de dades SQLite o MySQL i executa una consulta SELECT per mostrar registres per consola.
