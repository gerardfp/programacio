Exercici: Jerarquia Workers

Herència i Polimorfisme: Workers

Implementa l'estructura jeràrquica d'empleats d'una organització:

classDiagram Empleado <|-- Directivo Empleado <|-- Operario Operario <|-- Oficial Operario <|-- Tecnico class Empleado { +String nombre +Empleado(String nombre) +getNombre(): String +toString(): String } class Directivo { +toString(): String } class Operario { +toString(): String } class Oficial { +toString(): String } class Tecnico { +toString(): String }

La sortida per consola en mostrar la llista d'empleats ha de reflectir la seva cadena jeràrquica mitjançant toString().
