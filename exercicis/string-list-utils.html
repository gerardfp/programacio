Exercici: List String Utils

Utilitats estàtiques amb List<String>

Crea una classe d'utilitats anomenada StringListUtils amb els següents mètodes static:

  • static int countOccurrences(List<String> llista, String text): Compta el nombre de vegades que apareix un text a la llista.

  • static String join(List<String> llista, String separador): Concatena els textos d'una llista utilitzant el separador indicat.

  • static List<String> merge(List<String> l1, List<String> l2): Retorna una nova llista que conté tots els elements de la primera seguits dels de la segona, sense modificar les originals.

  • static List<String> removeMatches(List<String> llista, String text): Retorna una nova llista sense els elements que coincideixin amb el text.

  • static List<String> repeat(String text, int cops): Retorna una llista amb el text repetit el nombre de cops indicat.
