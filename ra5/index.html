Format de dades per consola i Text Blocks

Java ofereix eines elegants per formatar taules i missatges amb precisió numèrica:

void main() { String producte = "Portàtil"; double preu = 899.95; int quantitat = 2; // printf permet indicar amplada i decimals: %s (text), %d (enter), %.2f (decimal amb 2 posicions) System.out.printf("Producte: %-15s | Unitats: %2d | Preu: %8.2f€%n", producte, quantitat, preu); // Text Blocks per a plantilles de text multilínia netes: String factura = """ =========== FACTURA SIMPLIFICADA =========== Article: %s Total: %.2f € ============================================ """.formatted(producte, preu * quantitat); println(factura); }

Fitxers de text amb java.nio.file

El paquet java.nio.file és l'estàndard modern de Java per treballar amb fitxers i carpetes, oferint les classes Path i Files:

Escriure a un fitxer de text

import java.nio.file.Path; import java.nio.file.Files; import java.io.IOException; void main() { Path cami = Path.of("notes.txt"); String dades = "Anna: 9.5\nJoan: 7.0\nMarc: 8.25\n"; try { Files.writeString(cami, dades); println("Fitxer desat correctament a: " + cami.toAbsolutePath()); } catch (IOException e) { println("Error en escriure el fitxer: " + e.getMessage()); } }

Llegir d'un fitxer de text

import java.nio.file.Path; import java.nio.file.Files; import java.io.IOException; import java.util.List; void main() { Path cami = Path.of("notes.txt"); try { // Opció 1: Llegir tot el fitxer com un sol String String contingut = Files.readString(cami); println("Contingut complet:\n" + contingut); // Opció 2: Llegir línia per línia en una List List linies = Files.readAllLines(cami); println("Total de línies: " + linies.size()); } catch (IOException e) { println("Error en llegir el fitxer: " + e.getMessage()); } }

Fonaments d'interfície gràfica (GUI)

En el desenvolupament d'aplicacions amb interfície d'usuari visual, els components (finestres, botons, camps de text) es basen en el patró d'esdeveniments:

  • L'usuari fa una acció (clic de ratolí, tecla premuda).
  • El sistema operatiu i la biblioteca gràfica notifiquen a un controlador d'esdeveniments (*Event Listener*).
  • El programa executa el mètode associat a aquest esdeveniment per actualitzar la vista.
