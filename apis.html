Biblioteques del JDK

🚀 Hay una API para (casi) todo

Hasta ahora has aprendido a programar. Pero Java tiene una biblioteca enorme que permite hacer muchísimas cosas sin tener que programarlas desde cero.

Aquí tienes pequeñas piezas de Lego: cada una hace una cosa sencilla. Prueba a cambiar sus parámetros, repetirlas, combinarlas con if, for, while o Random... ¿Qué serías capaz de construir?

💡 La idea: no necesitas aprenderte estas API. Descubre que existen y experimenta con ellas.

🪟 Ventanas

API Con Java puedo... Snippet
JOptionPane 💬 Mostrar un mensaje JOptionPane.showMessageDialog(null, "¡Hola!");

Muestra ¡Hola! en una ventana.
JOptionPane ❓ Preguntar algo JOptionPane.showInputDialog("¿Cómo te llamas?");

Muestra una ventana donde el usuario puede escribir una respuesta.
JOptionPane ⚠️ Mostrar una advertencia JOptionPane.showMessageDialog(null, "¡Cuidado!");

Muestra un mensaje emergente.

🎵 Hacer música

Java puede controlar un sintetizador MIDI. No necesitas ningún archivo de sonido: puedes generar las notas directamente desde el programa.

API Con Java puedo... Snippet
javax.sound.midi 🎵 Tocar una nota canal.noteOn(60, 100);

Hace sonar la nota MIDI número 60.
javax.sound.midi 🔇 Dejar de tocar una nota canal.noteOff(60);

Deja de sonar la nota MIDI número 60.
javax.sound.midi 🎹 Cambiar de instrumento canal.programChange(80);

Cambia el instrumento utilizado por el sintetizador.
javax.sound.midi 🎵 Tocar una melodía for (int n : new int[]{60, 62, 64, 65, 67, 69, 71, 72}) { canal.noteOn(n, 100); Thread.sleep(300); canal.noteOff(n); }

Toca una escala musical. Cambia las notas o la duración y crea tu propia melodía.

Graphics2D ⭕ Dibujar un círculo g.drawOval(50, 50, 100, 100);

Graphics2D 🟥 Dibujar un rectángulo g.fillRect(50, 50, 100, 100);

Dibuja un rectángulo relleno.
Graphics2D 🔤 Dibujar texto g.drawString("¡Hola!", 50, 50);

Dibuja un texto en la superficie gráfica.

🌐 Hacer que dos ordenadores hablen

Estas API permiten que dos programas que están en distintos ordenadores intercambien datos a través de una red.

API Con Java puedo... Snippet
Socket 🌐 Conectarme a otro ordenador new Socket("192.168.1.50", 5000);

Intenta conectar con un programa que está esperando en ese ordenador y puerto.
Socket 📤 Enviar un mensaje socket.getOutputStream().write("¡Hola!".getBytes());

Envía un mensaje al otro programa.
ServerSocket 📡 Esperar a otro ordenador new ServerSocket(5000).accept();

Espera hasta que otro programa se conecte al puerto 5000.

🤯 Y ahora... combina las piezas

Lo interesante no es aprender estas instrucciones de memoria. Lo interesante empieza cuando las combinas con lo que ya sabes.

🤖 Abrir un programa y escribir dentro

new ProcessBuilder("notepad").start(); Thread.sleep(2000); new Robot().type("¡Esto lo ha escrito Java!");

Java abre el Bloc de notas, espera dos segundos y escribe en él. ¿Qué podrías hacer si cambias el texto, el tiempo y las acciones del robot?

🎵 Componer una canción

int[] notas = {60, 62, 64, 65, 67, 69, 71, 72}; for (int nota : notas) { canal.noteOn(nota, 100); Thread.sleep(300); canal.noteOff(nota); }

Cambia las notas. Cambia la duración. Repite algunas. Cambia el instrumento. Añade silencios. ¿Puedes hacer que Java toque una canción?

🖱️ Crear una automatización

Robot r = new Robot(); r.mouseMove(500, 300); Thread.sleep(500); r.click(); Thread.sleep(500); r.type("Hola");

Has construido una pequeña macro. Ahora puedes cambiar las coordenadas, las esperas y las acciones. ¿Puedes automatizar una tarea que haces habitualmente?

🧱 Piensa en piezas de Lego: una instrucción puede parecer poca cosa. Pero puedes repetirla, cambiar sus parámetros y combinarla con otras. Muchas cosas grandes empiezan con una pieza muy pequeña.
